# Changelog

## 0.1.0 - 2026-08-05

- Add validated immutable univariate time-series data.
- Add deterministic baseline, exponential smoothing, and Holt-Winters forecasts.
- Add classical seasonal decomposition and period diagnostics.
- Add chronological backtesting, model selection, and forecast combinations.
- Add point-forecast metrics, residual diagnostics, and stable reports.
- Add transformations, rolling features, scalers, statistics, feature matrices, and
  timestamp alignment.
- Add 102 tests, five executable examples, CI, and source auditing.
